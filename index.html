「Webコンテンツ作成」の成果

本テーマについて

  • 目的：情報工学の専門科目の基礎知識を応用して実践的な能力を修得する。
  • 目標：手順書を読み、実験を行い、レポートにより報告するという実験の一連の流れを実践できることと、HTML等を用いたWebページ作成ができること。

プロジェクト課題について

このプロジェクトはHTML、CSSとJavaScriptの要素を組み合わせ、上手に使ってグルメ検索結果のページを作成する課題である。具体的に、八王子の周辺の居酒屋の検索結果のページを作成した。 各店の住所、予算、営業時間、ジャンルなどの情報を記載することと、各店の写真、店へのリンクを検索で表示させるというプロジェクトである。 文字の大きさや太さ、画像の大きさ、ページの構成などを考えて表示を編集し、なるべくユーザーがページに写ってる情報を見やすいように作成した。

プロジェクト課題で作成したページ： project.html

数当てゲーム

Java scriptとHTMLを使って、数当てゲームというプログラムを作りました。このプログラムは、1～10の乱数で正解を生成し、ユーザーが3回以内にその数字を当てるゲームです。 「予想」ボタンを押すごとに予想回数がカウントされ、入力値と正解を比較します。正解なら「正解です」、不正解なら「もっと大きい／小さい」とヒントをリアルタイムに表示します。 3回間違えるとゲーム終了で正解を発表します。4回目以降の予想は無効となり、終了メッセージ等のメッセージを表示して不正な操作を防ぐ設計にしました。プログラムの動作確認だけでなく、 条件分岐やカウント処理などの学んだことを応用し、作成しています。

数当てゲームのページ：kazuate.html

各授業回の学習事項

第1回 WWWとHTML

HTMLのコマンド（約束文、タイトルなど）、画像の埋め込み仕方とハイパーリンクの仕方を学習し、グルメ検索ページの作成に使いました。 また、MDN Web Docs で HTML 要素を検索できることを学習した。

演習の成果： 演習1-4:HTMLのさまざまな要素

第2回 CSSによる Web ページの装飾

CSSを使い、Webサイトのレイアウトを作る演習をした。タイトルの色を変えたり、バックグラウンドの色を変えたり、 ウェブベージの見た目をより綺麗にする方法を学習した。また、Webサイト内での設定でWeb開発ツールを使い、 直接Webサイトを編集することを学習した。

演習の成果： 演習2-3:CSSによるWebサイト編集演習

第3回 JavaScript の基本

JavaScriptのプログラムの試しのためのコンソール機能とJavaScriptのコマンドについて学習した。具体的に、 let、function、Console.log()やブレークポイントなどを使い、コンソールでオブジェクトプログラムの作成、デバッグ、編集の演習をした。

演習の成果： 演習3-6:Web上でのコンソールの使い方演習

第4回 DOM と JavaScript

様々なinput要素の種類とその要素がブラウザーにどのような表示をするかというのと、要素にテキストの参照・変更や属性を参照する構文を学習した。 また、イベントパンドラの登録と動作確認を学び、学習したこと使い、を２つの数字を足し算するページを編集する演習をした。

演習の成果： 演習4-10: 足し算ページ演習

第5回 イベント処理

DOMによる要素の新規作成、編集、削除を学習しました。 具体的には、コンソールで要素を新規作成したり、ある要素の内部・直後に他の要素を配置したり、要素の属性を設定したり、要素を削除したりしました。 その演習として、大学のキャンパスの住所と、工学部の学科名一覧を表示する JavaScript プログラムを完成しました。

演習の成果： 演習5-7 DOMプログラミング

工夫点，苦心点，強調点，感想

　　工夫点は、宿題を友達と相談して、編集しやすいようにdivやp要素を書き方を学びました。 最初の自分で作ったHTMLはページ上で写されているものは読みやすいが、HTMLの書き方には全く気にしていなかったです。 しかし、第二回、第三回目の授業に自分が作った最初とHTMLを見たら、とても編集しづらく見えると思いました。 そこで、編集しやすいような形にうまくdivとpの要素を使うことにしました。
　　苦心点はテキストやボタンなどの表示をどうすればページの真ん中に映る点です。 justify_contentを使っても文字がそのまま左側から動かないということがあって、とても困りました。 そこで、工夫したことは、第二回目の2-3演習を思い出して、箱の中に入れれば、display: flexを使い、自由に動かすことができると気づき、 真ん中に配置したいものをある箱に入れれば真ん中に表示すようにすることができました。
　　また、Webページのデザインの構成などにも苦心しました。確かに、この授業はHTMLなどWebページの作成のための授業で、 Webページが順調に動くことができればそれでいいです。しかし、人に見やすい、操作しやすいように表示を編集することもWebページの作成の一つの大事なのではないかと思います。 Webページを見やすくするだけではなく、目に優しいWebページを作るには優れたセンスが必要となる。この授業をとってそのことに気づきました。
　　強調点としては、授業中で学ぶだけではなく、家でも作業を続けることが大事という点です。ノートを取るように授業中のノートは書けるものだけを書いて最初の書いたコードみたいに読みづらいです。 そこで、家でコードを復習し、読みやすくあとが編集しやすくすることが大切です。そうすれば、次の授業や作業をするときに整理しやす苦なり、スムーズに授業フォローできるようになります。
　　この授業を受けて、Webページの中では一つのプログラミング言語だけではなく、さまざまなプログラミング言語を使っていることを知りました。 HTML、CSS、JavaScriptのそれぞれの役割を学ぶことができて、今は色々なWebサイトを訪問する際にこのページの構成や「どうやって作ったか」と考えながら見てます。その上に、Webページへの新しい見方を習得しました。 自分が訪問するWebページの構成は自分将来作るWebページへの参考になるという意識ができました。この授業では学んだ知識を実際に演習することが魅力的でした。
